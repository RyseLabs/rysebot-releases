# Rysebot downloads

Public releases of [Rysebot](https://rysebot.com) — an assistant for your whole computer.

- **Rysebot for Windows** — `Rysebot-Setup-x.y.z.exe`. Windows 10 / 11. The installer is not code-signed yet, so
  Windows SmartScreen shows "Windows protected your PC": choose **More info → Run anyway**.
- **Rysebot browser extension (preview)** — `rysebot-extension-x.y.z.zip`, until it is listed in the Chrome Web
  Store: unzip it, open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked** and pick the
  unzipped `rysebot-extension` folder. Works in Chrome, Edge and Brave.

Both need an [OpenRouter](https://openrouter.ai/settings/keys) key, entered once inside the app.

Get the latest from the [Releases](../../releases/latest) page or from rysebot.com.
